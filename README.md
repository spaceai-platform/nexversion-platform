# NexVersion Platform

A premium static prototype for the NexVersion AI workspace UI.

## What changed

- Modern floating workspace shell with glass surfaces, stronger hierarchy, and editorial typography.
- Responsive navigation, stacked mobile layouts, touch-friendly controls, and adaptive preview sizing.
- Interactive preview system with product, brief, and metrics modes plus desktop/tablet/mobile frames.
- AI thread, task stack, collaborator rail, and design-token inspector to make the workspace feel closer to Linear, Framer, Base44, and Notion.

## Run locally

```bash
npm start
```

Then open <http://localhost:4173>.

## Check JavaScript

```bash
npm run check
```
