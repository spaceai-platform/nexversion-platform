# Nexversion — 28-Day Curriculum Upgrade
**Status: Draft course package; not deployed to the live site.**

Original 28-lesson programme. Each lesson is designed around a 20-minute study session, a worked demonstration, guided exercise, portfolio output and knowledge check.

## Week 1 — Foundations and practical prompting

### Day 1: Understand AI without the hype
**Tools:** ChatGPT or Gemini
**Learning outcome:** Explain generative AI, strengths, limitations, hallucinations and when human review is necessary.
**Demonstration:** Demonstrate the full process for: understand ai without the hype, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Compare an AI answer with a trustworthy source and mark three claims requiring verification.
**Deliverable:** A one-page AI opportunity and risk map
**Knowledge check:** Identify two common AI failure modes

### Day 2: Choose a useful problem
**Tools:** ChatGPT
**Learning outcome:** Define a specific user, task, source material, desired result and success criteria.
**Demonstration:** Demonstrate the full process for: choose a useful problem, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Turn a vague ambition into a measurable task brief.
**Deliverable:** An AI task brief
**Knowledge check:** Select the task that has observable success criteria

### Day 3: Write a prompt that works
**Tools:** ChatGPT or Claude
**Learning outcome:** Use goal, audience, context, constraints and output format deliberately.
**Demonstration:** Demonstrate the full process for: write a prompt that works, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Rewrite three weak prompts and compare the resulting outputs.
**Deliverable:** Three improved prompts with annotations
**Knowledge check:** Identify missing context in a prompt

### Day 4: Iterate and improve
**Tools:** ChatGPT
**Learning outcome:** Use an iterative cycle: draft, inspect, challenge, revise and accept.
**Demonstration:** Demonstrate the full process for: iterate and improve, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Refine an email prompt over three cycles while recording changes.
**Deliverable:** Before-and-after prompt log
**Knowledge check:** Choose the strongest revision strategy

### Day 5: Verify before you trust
**Tools:** Perplexity plus primary sources
**Learning outcome:** Differentiate source-backed claims, citation links, speculation and out-of-date answers.
**Demonstration:** Demonstrate the full process for: verify before you trust, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Fact-check a short AI-written guide against two primary sources.
**Deliverable:** A verification checklist
**Knowledge check:** Spot unsupported claims and misleading citations

### Day 6: Protect private information
**Tools:** ChatGPT/Gemini privacy controls
**Learning outcome:** Understand personal-data minimisation, confidential files, copyright and safe sharing.
**Demonstration:** Demonstrate the full process for: protect private information, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Redact a mock customer note before using it in an AI prompt.
**Deliverable:** A safe-input policy
**Knowledge check:** Identify what cannot be pasted into a public assistant

### Day 7: Week 1 challenge: useful assistant
**Tools:** ChatGPT or Claude
**Learning outcome:** Combine task design, prompting, verification and safe use.
**Demonstration:** Demonstrate the full process for: week 1 challenge: useful assistant, using a fictional, non-sensitive scenario. Explain each prompt, the tool output, at least one observed limitation, and a human quality check.
**Exercise:** Create a reusable assistant prompt for one task, test it, and document limitations.
**Deliverable:** Foundation project and reflection
**Knowledge check:** Rubric: clarity, safety, evidence, usefulness
